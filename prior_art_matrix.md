# Prior Art Matrix — Black Book Engine

RULE: Every formal claim must ask:
1. Does Jung define this?
2. Does existing Jungian textbook define this?
3. Does the supplied source define this?
4. Does established analytical psychology define this?
5. Does an existing mathematical model already define this?
6. Does an existing computational symbolic model already define this?
7. Does prior literature contain substantially the same structure?

If YES → mark NON_NOVEL  
If UNKNOWN → mark PRIOR_ART_REVIEW_REQUIRED  
If evidence supports novelty → mark NOVEL_CANDIDATE
